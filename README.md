# 棋类游戏（boardgames）

**用 Python + Pygame 从零写棋类游戏，顺便把"怎么做"讲清楚。**

一个可插拔的桌面棋类框架 + 四个成品游戏：**步步为营**（墙棋 / Quoridor）、
**重力四子棋**（Connect Four）、**大力士棋**（Abalone）、**昆虫棋**（Hive）。

- **依赖只有一个 `pygame-ce`**。棋盘几何、AI 搜索、界面控件、动画物理、摄像机全部手写，
  不引第三方游戏框架 / GUI 库 / 数学库 —— 这个项目的一半价值在**可读、可学习的实现**。
- **规则 / AI / 界面三层解耦**。接入新棋类只需写**规则引擎 + 一块棋盘视图**，
  侧栏、主题、控件、AI 调度、悔棋、游戏大厅、规则浮层、设置持久化**全部自动复用**。

想了解架构 → [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)；
想接一个新棋类 → [`docs/ADDING_A_GAME.md`](docs/ADDING_A_GAME.md)（含模板与坑清单）。

## 快速开始

需要 [uv](https://docs.astral.sh/uv/)（Python 3.13）。

```bash
uv sync              # 安装依赖（只有 pygame-ce）
uv run boardgames    # 启动（先进游戏选择大厅）
uv run pytest        # 运行测试
uv run ruff check src tests scripts
```

常用参数：

```bash
uv run boardgames --game connect4              # 直接进某个棋类（quoridor/connect4/abalone/hive）
uv run boardgames --scene match                # 跳过大厅直接进对局
uv run boardgames --mode eve --p1 mcts --p2 minimax      # AI 自对弈
uv run boardgames --game connect4 --cols 8 --rows 7      # 自定义四子棋盘
uv run boardgames --game quoridor --size 11 --walls 15   # 自定义墙棋棋盘
uv run boardgames --window 1000x640            # 强制窗口尺寸（小屏 / 调试布局）
uv run python scripts/benchmark_ai.py          # AI 性能基准
```

**离屏截图**（自检 / 看布局用，不需要显示器）：

```bash
uv run boardgames --offscreen --screenshot lobby.png --scene lobby
uv run boardgames --offscreen --screenshot c4.png --game connect4 --scene match --demo 8 --hover drop
uv run boardgames --offscreen --screenshot q.png  --game quoridor --scene match --demo 6 --hover wall-h
uv run boardgames --offscreen --screenshot aba.png --game abalone --scene match --demo 24 --hover aba-select
uv run boardgames --mode pvp --offscreen --screenshot hive.png --game hive --scene match --demo 18 --hover hive-place
```

> 昆虫棋截图**必须加 `--mode pvp`**：落点提示挂在交互态上，配置里若存了 `mode=eve`，
> 会拍到"一个落点都没有"的画面。
> 昆虫棋棋盘无边界，截图前会自动把镜头拉回蜂巢（按 `F` 是同一个动作）。

### 两个容易混淆的开关

| 开关 | 含义 |
|---|---|
| `--frameless`（别名 `--headless`） | **无边框窗口**：不要系统标题栏，改由程序自己画一条（标题 / 最小化 / 全屏 / 关闭 / 拖动），**窗口照常显示、照常能玩**。默认开启（侧栏「界面与操作 → 无边框窗口」，改完需重启程序）。用 `--windowed` 回到系统标题栏。 |
| `--offscreen` | **完全不显示窗口**：切 SDL dummy 驱动跑主循环，给 CI / 容器 / 跑批用。窗口开不出来时（无 `DISPLAY`、远程桌面断开）也会自动降级到它。 |

离屏模式配合 `--until-over` 可以跑到分出胜负（自动解除自对弈的暂停、关掉动画、放开帧率，
默认真实时间上限 600s，用 `--timeout` 调）；`--fast-ai` 把 AI 调成演示速度（不写回配置文件）。

窗口默认 1180×780，会自动裁剪到不超过屏幕可用区域；可自由缩放，侧栏在小窗口下自动收窄并可滚动。

## 界面速览

**游戏选择大厅**：一张卡片一个游戏，卡片上只放**图标 + 名称 + 副标题 + 一行简介**。
卡片数据全部来自各 `Game` 类的元数据，**接第五个棋类时大厅零改动**。
也支持键盘：`←↑↓→` 选择、`Enter` 进入、`R` 看规则、`Esc` 退出。

卡片图标画的是**一局棋里的一个瞬间**，而不是抽象棋盘网格 ——
"三连 + 空一格"比点阵图案好认得多：

| 棋类 | 图标画的是什么 |
|---|---|
| 步步为营 | 己子被一面墙挡在正前方，只能走直角折线绕过去 |
| 重力四子棋 | 底行已经三连、第四格是虚线落点预览，最左一列两子叠着表示重力 |
| 大力士棋 | 一盘残局：中央三枚正把对手顶向虚线边界 |
| 昆虫棋 | 蜂后被围满五面、缺口那面闪着绿色虚线，外围虚线格表示棋盘还能往外长 |

**规则说明浮层**：大厅卡片底部、以及对局中棋盘右上角的「规则说明」按钮（快捷键 `H` / `?`）
打开同一块浮层，正文全部来自 `Game` 的 `goal` / `summary` / `rules` / `howto` / `tips`。
浮层是**模态**的（开着时吃掉全部事件），可滚动，`Esc` / `空格` / 点遮罩都能关掉。

## 玩法速览

完整规则（含边界情形）请按 `H` 在程序里看 —— 那份正文就是下面各节的展开版。

### 步步为营（墙棋 / Quoridor）

9×9 棋盘，双方各 **10 面墙**，棋子放在自己底边中央，**先走到对方底线者胜**。
每回合二选一：**走一格**（不能斜走、不能穿墙）或**放一面 2 格长的墙**。
双方棋子正面相邻时可以**跳过对方**；正后方被挡时可改跳左右侧。
放墙限制：不能重叠、不能交叉成「十」字（两端相接的 L / T 形合法）、
**放完墙双方都必须仍有路可走**、墙用完就只能走子。

### 重力四子棋（Connect Four）

7 列 × 6 行（可在侧栏调到 5-12 列 / 4-10 行），**连线数固定 4**。
轮流往任一未满列投子，棋子因重力落到该列最低空位；横 / 竖 / 斜先连成四子者胜，填满则平局。
落子动画是**真的物理模拟**：自由落体 → 触底回弹 → 阻尼衰减，用固定子步（1/240 秒）积分，
所以掉帧或切后台回来都不会炸开。

### 大力士棋（Abalone）

六边形棋盘 61 格，双方各 **14 枚**，**先把对手 6 枚棋子挤出棋盘者胜**。
每回合选 **1~3 枚连线的己方棋子**整体走一格：

| 走法 | 条件 |
|---|---|
| **直线移动** | 沿排列方向前后推进，**只有这种走法能推动对手** |
| **横移** | 平行于排列方向整排侧移，**不能推挤** |

推挤遵循**以多推少**：3 枚可推 1~2 枚，2 枚可推 1 枚，1 枚推不动任何子；数量相等形成对峙。
被推的最后一格要么空、要么是棋盘外缘（即"直接推出界"）。
三种官方起始布局（标准 / 比利时雏菊 / 德国雏菊）在侧栏切换，开局着法数分别为 44 / 52 / 80。

### 昆虫棋（Hive）

**无棋盘**抽象棋：棋盘就是棋子本身，双方各 **11 枚**（开扩展虫则各 14 枚），
**先把对方蜂后六面围满者胜**。每回合二选一：放一枚新虫，或移动一枚已入场的虫。

| 虫 | 枚数 | 走法 |
|---|---|---|
| 蜂后 | 1 | 沿蜂巢外缘滑动一格（**必须在自己第 4 回合结束前落下**，没落盘时谁都不能动） |
| 甲虫 | 2 | 走一格，**可以爬到别的棋上面**，也可以从堆上下来 |
| 蚱蜢 | 3 | 沿一个方向**直线跳过至少一枚棋**，落在第一个空格 |
| 蜘蛛 | 2 | **恰好滑动三格**，中途不能重复经过任何一格 |
| 兵蚁 | 3 | 沿蜂巢外缘**滑动任意距离** |

三条通用约束：**蜂巢必须始终一体**（拿掉一枚后不能裂成两半）；
**滑动门**（滑动时两侧的格子都比出发格和落点格更高就挤不过去，叠层上的棋不看门）；
**被压住的棋不能动也不能选**。扩展三虫（瓢虫 / 蚊子 / 鼠妇）在侧栏开关。
**一枚棋都走不了时必须停一手**（PassMove），连续两手 pass 判和；
和棋还有三种情形：双方蜂后同时被围满、同一局面出现三次、走到 400 手上限。

## 操作

**全程鼠标**。任何时候按 `H` 都能叫出当前棋类的完整规则。

| 棋类 | 交互 |
|---|---|
| 步步为营 | **右键**（或 `W`）切换「放墙模式」：鼠标吸附到最近的内部网格交点，画出幽灵墙（绿=可放 / 红=不可放），放完一面自动退出。横竖判定带**滞回**，预览不会乱跳；想手动换朝向按 `V` |
| 重力四子棋 | 鼠标移到某一列预览落点，点击投子 |
| 大力士棋 | **两段式点击**：点一枚己方子选中 → 再点同线的子可扩到 2~3 枚 → 点目标格出招。目标格画出虚线圆圈 + 方向箭头（绿=普通 / 琥珀=推动 / 红=挤出盘外），热区是整格且**画在棋子之上**（推挤目标格本身就是对手棋子所在的格） |
| 昆虫棋 | 点底部**手牌条**的虫卡 → 亮出所有可落点 → 再点一个绿点即放置；点棋盘上己方的棋 → 亮出可去格 → 再点即移动。**悬停**任意棋子会弹出悬停标识（虫种 + 归属，叠层时摊开写清谁压着谁）。滚轮以光标为锚缩放、按住左/中键拖动平移、`F` 把镜头拉回蜂巢。选鼠妇后绿点分两类（自己走 / 搬运目标） |

> **昆虫棋的棋子上只有"谁的"，虫种靠剪影 + 悬停标识。** 试过给八种虫各配一种颜色，
> 结果最抢眼的变成虫种色、"哪个是我的"反而要靠推理 —— 敌我识别优先级高得多。

### 快捷键

| 键 | 作用 |
|---|---|
| `U` / `N` / `R` | 悔棋 / 新局 / 认输（`R` 在大厅里是"看规则"，两边不冲突） |
| `H` / `?` | 打开规则说明浮层（对局与大厅都可用） |
| `W` / `V` | 开摆放墙模式 / 切换横竖朝向（**仅墙棋**） |
| `F` | 镜头回到蜂巢（**仅昆虫棋**） |
| `1`~`8` | 选中手牌条第 N 种虫（**仅昆虫棋**，再按一次取消） |
| `空格` / `S` | 暂停·继续 / 自对弈单步 |
| `Esc` | **分级**：关浮层 → 取消当前选择 → 退出放墙模式 → 回大厅 → 退出程序 |

### 对局模式与悔棋

侧栏顶部切换 **双人对战 / 人机对战 / AI 自对弈**，参数会**按当前模式 + 当前棋类自动精简**
（人机只问"我执哪一方 + 电脑用哪个引擎"；自对弈的两边都必须是 AI，候选里没有"人类"）。

- 双人同屏：回退 1 步；
- 人机：一直回退到**轮到你**为止（AI 已应招是 2 步），并立刻取消正在进行的搜索；
- AI 自对弈：回退 1 步并自动暂停。

**AI 自对弈默认暂停**：点侧栏「单步」或直接点棋盘推进一着，点「暂停 / 继续」（或空格）改为连续对弈。

## AI

两套算法共用同一个 `Game` 接口，可在侧栏随时切换对比：

- **Minimax（Alpha-Beta）**：负极大值 + Alpha-Beta + 迭代加深 + Zobrist 置换表。
  靠两层剪枝扛住组合爆炸：每个节点只看「对手最短路径附近」的少量墙 / 走法候选，
  并且超过「考虑放墙的层数」后只展开走子。
- **MCTS（UCT）**：UCB1 选点 + 惰性展开 + 启发式 rollout。
  rollout 沿**目标距离场**推进（保证单调收敛，不会来回振荡），并"越快取胜回报越高"塑形。
- 还有一个**随机引擎**做兜底与基准。

搜索跑在**后台线程**里（`AIWorker`），只把结果 `poll()` 回主循环；**AI 线程绝不触碰 pygame**。
所有参数改完**立刻生效**并自动持久化到 `config/settings.json`；改 AI 参数时若正在思考，
会立刻取消并按新参数重搜。

侧栏分组：**棋局设置 / 对局双方 / Minimax 参数 / MCTS 参数 / 评估权重 / 界面与操作**。
参数按棋类严格隔离（玩四子棋不会看到「每人墙数」），滑块也可以**点击右侧数值框直接键入**。
把 `board_size`、`abalone_setup` 这类参数加进 `RESTART_KEYS` 后，改动它们会重开一局。

实测吞吐（选引擎时的参考）：

| 棋类 | MCTS 迭代/秒 | 建议 |
|---|---|---|
| 重力四子棋 | ~2090 | Minimax 与 MCTS 都能下好 |
| 步步为营 | ~590 | Minimax depth 4 ≈ 80ms |
| 大力士棋 | ~180 | 把「着法候选上限」调到 20~32（开局 44~80 步） |
| 昆虫棋 | **~83** | 优先 Minimax（d4~6），候选上限 16~32；中局分支因子 100+ |

## 项目结构

```
src/boardgames/
├── core/           游戏无关抽象：State / Move / Game / SearchOptions / GameRegistry（仅标准库）
├── games/<key>/    一个棋类一个包：state / move / rules / heuristic / view（+ geometry / layouts）
├── ai/             engine（统一接口）/ minimax / mcts / tt / random_ai / worker（后台线程）
├── controller/     session.py：对局会话、模式、悔棋、AI 编排
├── settings/       ParamSpec 参数描述 + JSON 持久化
└── ui/             scene / window / chrome / lobby / match_scene / sidebar / rules_panel /
                    camera / animation / theme / fonts / render / board_view / widgets
tests/              按被测层次分目录（core / games / ai / settings / ui）
scripts/            benchmark_ai.py（AI 基准）、fetch_hive_assets.py（昆虫棋素材下载）
docs/               ARCHITECTURE.md（架构总览）、ADDING_A_GAME.md（新增棋类指南）
```

详细分层约定、核心抽象、AI/UI 子系统与坑清单见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)。

## 新增一个棋类

只需 **6 个文件 + 3 处注册**，侧栏 / 主题 / 控件 / AI 调度 / 悔棋 / 大厅 / 规则浮层全部自动复用：

1. `games/<key>/`：`state.py`（不可变局面 + `zobrist_hash`）、`move.py`（`frozen dataclass`）、
   `rules.py`（`Game` 子类，含大厅与规则浮层要用的元数据 ClassVar）、`heuristic.py`、`view.py`；
2. `core/registry.py` 的 `build_default_registry()` 里注册游戏；
3. `app.py` 的 `register_builtin_views()` 里注册视图工厂；
4. `settings/schema.py` 里加专属参数（**必须打 `games=(key,)` 标**）。

完整步骤、代码模板、可选钩子（摄像机 / 悬停提示 / 放置模式）与**坑清单**见
[`docs/ADDING_A_GAME.md`](docs/ADDING_A_GAME.md)。

## 测试

```bash
uv run pytest              # 全部
uv run pytest tests/games  # 只跑规则
uv run pytest tests/ai     # 只跑 AI 契约
uv run pytest tests/ui     # UI 冒烟（SDL dummy 驱动，不需要显示器）
```

覆盖重点：每个棋类的规则逐条（合法性 / 边界 / 胜负 / 平局 / 哈希一致性 / 评估反对称性）、
rollout 必然收敛、AI 统一契约（永远返回合法着法、时限生效、可复现、可取消）、
参数校验与持久化、参数按棋类隔离、场景切换、以及一批**回归用例**（弹跳物理的掉帧稳定性、
鼠标悬停不会折叠分组、AI 等待落子期间不重开搜索、滑块只有按住才跟随鼠标、
窗口尺寸不超出屏幕）。

**渲染类 bug 用断言数据结构的测试永远抓不到** —— 所以大厅图标、棋子颜色、皇冠、落点提示
都做**像素级断言**（画一帧再取像素），昆虫棋的坐标换算还在 5 种缩放 + 平移组合下逐一验证。

## 一些刻意的取舍

| 取舍 | 原因 |
|---|---|
| **棋盘渲染不做通用化** | 墙棋的槽位、围棋的点、国象的格子、大力士棋的六边形差异太大，强行统一反而难维护。只共享侧栏 / 控件 / AI 调度 / 场景 |
| **AI 用线程而不是进程** | 纯 Python 搜索会与主循环争 GIL，但主循环大部分时间在等待，实测 60 FPS 稳定 |
| **卡片只放三行字，规则全进浮层** | 卡片上塞进去的规则必然是删减版，而删减过的规则等于没规则 |
| **图标画局面而不是棋盘** | 抽象棋盘网格在 96px 里辨识度极低，"三连 + 空一格"一眼就能读懂玩法 |
| **四子棋的连线数固定 4** | 只开放棋盘尺寸，规则更纯粹，侧栏也不会多出无意义的选项 |
| **大力士棋是唯一真正用 `max_branch` 的棋类** | 开局就有 44~80 个着法，不裁剪搜索树会爆；四子棋分支本来就小，裁剪反而有害 |
| **昆虫棋显式生成「停一手」** | 规则规定一枚棋都动不了时必须 pass。缺了它，MCTS 的 rollout 会向空着法表索取着法直到抛错，而 AI 线程会吞掉异常 —— 表现就是"AI 突然不下棋了" |
| **昆虫棋的局面哈希先做平移归一化** | 蜂巢的绝对坐标没有意义，不归一化会让置换表与 MCTS 节点复用全部失效 |
| **场景用转发 property 兼容旧测试** | `GameWindow` 把 `session` / `view` 等方法转发给当前 `MatchScene`，因此既有测试一行都不用改 |
| **"无边框"和"不显示窗口"是两个开关** | 混成一个的后果是"想去掉标题栏的人得到了一个看不见的窗口" |
| **`--frameless` 下拖窗只在 Windows 生效** | 借的是系统能力（`WM_NCLBUTTONDOWN` + `HTCAPTION`）。别的平台拖不动，但三个按钮和快捷键都正常，不抛异常也不卡住 |
