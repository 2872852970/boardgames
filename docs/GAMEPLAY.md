# 玩法与操作

六个棋类的完整规则、界面说明与操作方式。**更权威的那一份在程序里** ——
任何时候按 `H`（或点「规则说明」）都能叫出当前棋类的完整规则，那里是各
`Game` 类元数据的原样呈现，改代码就会同步变。

- 想跑起来 / 调参数 / 截图 → [`USAGE.md`](USAGE.md)
- 想了解分层与设计 → [`ARCHITECTURE.md`](ARCHITECTURE.md)
- 想接一个新棋类 → [`ADDING_A_GAME.md`](ADDING_A_GAME.md)

## 1. 界面速览

**游戏选择大厅**：一张卡片一个游戏，卡片上只放**图标 + 名称 + 副标题 + 一行简介**，
底部一个「规则说明」按钮。卡片数据全部来自各 `Game` 类的元数据，
**接第五个棋类时大厅零改动**。键盘：`←↑↓→` 选择、`Enter` 进入、`R` 看规则、`Esc` 退出。

卡片图标画的是**一局棋里的一个瞬间**，而不是抽象棋盘网格 ——
"三连 + 空一格"比点阵图案好认得多：

| 棋类 | 图标画的是什么 |
|---|---|
| 步步为营 | 己子被一面墙挡在正前方，只能走直角折线绕过去 |
| 重力四子棋 | 底行已经三连、第四格是虚线落点预览，最左一列两子叠着表示重力 |
| 大力士棋 | 一盘残局：盘上双方都还剩一批子，盘外躺着已被挤出去的半透明子 |
| 昆虫棋 | 蜂后被围满五面、缺口那面闪着绿色虚线，外围虚线格表示棋盘还能往外长 |
| 点格棋 | 4×4 点阵上已画一圈边、圈里一个琥珀色占领格，示意"画满四条边即占格" |
| 播棋 | 上下两排小坑里散着种子圆点、两端各一个彩色仓库，示意"把种子搬进仓库" |

**对局界面**：左侧棋盘 + 右侧控制面板。棋盘左上角是悬停提示胶囊，
右上角是「规则说明」按钮，底部是操作提示行（昆虫棋还有一条手牌条）。

**侧栏**（自上而下）：

| 区域 | 内容 |
|---|---|
| 固定头部 | 游戏名（右侧是回合 / 思考 / 结果指示）+ 对局模式切换（双人 / 人机 / AI 自对弈）+ **两张玩家卡片**（颜色、身份、当前棋类的进度数字；轮到谁谁加描边高亮） |
| 滚动区 | **棋局设置**（公共选项，永远排第一）→ AI 状态行 → 对局双方 |
| 固定底栏（两行） | 第一行：新局 / 悔棋；第二行：大厅 / 设置 /（自对弈时）暂停 · 单步 |

三条容易忽略的规矩：

- **棋局设置是公共选项，且开局后锁定。** 棋盘尺寸、起始布局、扩展虫这些
  决定"这一局怎么摆"的参数，只有在**还没落子**的时候能改（没落子时改了就等于重开，
  落子之后整组变灰、标题旁会写「已开始 · 开新局可改」）。
- **三种模式（双人 / 人机 / AI 自对弈）同样只在开局前可选。** 它决定"这一局谁在跟谁下"，
  落子后分段控件会变灰，模式下方那行一直写着当前状态（"三种模式在对局开始后锁定"
  / "已开始 · 开新局可改"）。
- **先手固定为玩家 1**，界面上没有这个选项了（规则层的 `first_player` 参数仍在，供测试用）。
- **每一项都能恢复初始值**：行右侧有个小 ↺，**改过的项**才亮起来，点一下恢复该项默认值；
  「设置」浮层右上角另有「全部恢复默认」（只重置当前这一局用得上的项）。
- **「边下边调」的留在侧栏，其余收进「设置」浮层。** 引擎参数（搜索深度、模拟次数、
  思考时限…）、评估权重、界面与操作都在底栏「设置」按钮里 —— 它们是"调一次就不再碰"
  的东西，留在侧栏只会把常用项挤下去。浮层里参数**按当前棋类与参战引擎自动过滤**：
  双人对战看不到 AI 旋钮，人机 Minimax 局也不会多出一整套 MCTS 参数。浮层分**两列**
  排布，**卡片尺寸固定**（折叠 / 展开分组只改变滚动内容，卡片本身不会忽大忽小），
  内容超出时用滚动条。
- **分组标题都可以点**：侧栏与「设置」浮层里每个分组标题（`Minimax 引擎`、`评估权重`…）
  点一下收起、再点展开，标题左边的三角形跟着转。收起的分组不占滚动区，卡片也会跟着缩。
- **数值框可以直接键入**：点任意滑轨右边的数字格子输入数值（回车确认 / Esc 取消），
  侧栏与「设置」浮层里都一样。

**落子动画播完 AI 才会动手**：人机 / 自对弈里，上一手的落子动画没结束前 AI 不会落子，
所以不会出现"我的子还没落地、对面已经下完"。

**对局开始时永远是双人对战**：从大厅进入某个棋类时，模式会复位到「双人对战」，
不继承上一局存下来的"人机 / 自对弈"。

## 2. 玩法速览

### 步步为营（墙棋 / Quoridor）

9×9 棋盘，双方各 **10 面墙**，棋子放在自己底边中央，**先走到对方底线者胜**。
每回合二选一：**走一格**（不能斜走、不能穿墙）或**放一面 2 格长的墙**。
双方棋子正面相邻时可以**跳过对方**；正后方被挡时可改跳左右侧。
放墙限制：不能重叠、不能交叉成「十」字（两端相接的 L / T 形合法）、
**放完墙双方都必须仍有路可走**、墙用完就只能走子。

### 重力四子棋（Connect Four）

7 列 × 6 行（可在侧栏调到 5-12 列 / 4-10 行），**连线数固定 4**。
轮流往任一未满列投子，棋子因重力落到该列最低空位；横 / 竖 / 斜先连成四子者胜，填满则平局。
落子动画是**真的物理模拟**：自由落体 → 触底回弹 → 阻尼衰减，用固定子步（1/240 秒）积分，
所以掉帧或切后台回来都不会炸开。

### 大力士棋（Abalone）

六边形棋盘 61 格，双方各 **14 枚**，**先把对手 6 枚棋子挤出棋盘者胜**。
每回合选 **1~3 枚连线的己方棋子**整体走一格：

| 走法 | 条件 |
|---|---|
| **直线移动** | 沿排列方向前后推进，**只有这种走法能推动对手** |
| **横移** | 平行于排列方向整排侧移，**不能推挤** |

推挤遵循**以多推少**：3 枚可推 1~2 枚，2 枚可推 1 枚，1 枚推不动任何子；数量相等形成对峙。
被推的最后一格要么空、要么是棋盘外缘（即"直接推出界"）。
三种官方起始布局（标准 / 比利时雏菊 / 德国雏菊）在侧栏切换，开局着法数分别为 44 / 52 / 80。

### 昆虫棋（Hive）

**无棋盘**抽象棋：棋盘就是棋子本身，双方各 **11 枚**（开扩展虫则各 14 枚），
**先把对方蜂后六面围满者胜**。每回合二选一：放一枚新虫，或移动一枚已入场的虫。

| 虫 | 枚数 | 走法 |
|---|---|---|
| 蜂后 | 1 | 沿蜂巢外缘滑动一格（**必须在自己第 4 回合结束前落下**，没落盘时谁都不能动） |
| 甲虫 | 2 | 走一格，**可以爬到别的棋上面**，也可以从堆上下来 |
| 蚱蜢 | 3 | 沿一个方向**直线跳过至少一枚棋**，落在第一个空格 |
| 蜘蛛 | 2 | **恰好滑动三格**，中途不能重复经过任何一格 |
| 兵蚁 | 3 | 沿蜂巢外缘**滑动任意距离** |

三条通用约束：**蜂巢必须始终一体**（拿掉一枚后不能裂成两半）；
**滑动门**（滑动时两侧的格子都比出发格和落点格更高就挤不过去，叠层上的棋不看门）；
**被压住的棋不能动也不能选**。扩展三虫（瓢虫 / 蚊子 / 鼠妇）在侧栏开关。
**一枚棋都走不了时必须停一手**（PassMove），连续两手 pass 判和；
和棋还有三种情形：双方蜂后同时被围满、同一局面出现三次、走到 400 手上限。

### 点格棋（Dots and Boxes）

**N×N 点阵**（默认 6×6 点 = 5×5 方格，可在侧栏调 3~9）围成 (N-1)×(N-1) 个方格。
双方轮流在**相邻两点间画一条边**（水平或垂直），一条边只能画一次；
**画满一个方格的第四条边即占领该格**，由画最后一条边的人获得，并**再走一手**。
所有边画完后格子多者胜，打平则平局。双方画的边用各自颜色区分（玩家 1 琥珀、玩家 2 蓝），
已占领的方格也染上对应颜色。

### 播棋（Mancala / Kalah）

**2 排 × 6 列共 12 个小坑**（可调每侧 3~8 坑），两端各一个大坑（仓库），每坑初始 4 枚种子。
轮到谁就从**自己一侧**任意非空小坑取出全部种子，沿逆时针逐坑播一粒，
经过己方仓库也播一粒、**跳过对手仓库**。两条关键规则：

| 落点 | 结果 |
|---|---|
| 最后一粒落在**己方仓库** | **再走一手**（额外回合） |
| 最后一粒落在**己方空坑** | 这一粒连同**正对面**对手坑里的种子一起收进己方仓库（捕获） |

某方所有小坑清空时结束，对手收走自己坑里剩余种子，仓库多者胜。

## 3. 操作

**全程鼠标**。任何时候按 `H` 都能叫出当前棋类的完整规则。

| 棋类 | 交互 |
|---|---|
| 步步为营 | **右键**（或 `W`）切换「放墙模式」：鼠标吸附到最近的内部网格交点，画出幽灵墙（绿=可放 / 红=不可放），放完一面自动退出。横竖判定带**滞回**，预览不会乱跳；想手动换朝向按 `V` |
| 重力四子棋 | 鼠标移到某一列预览落点，点击投子 |
| 大力士棋 | **两段式点击**：点一枚己方子选中 → 再点同线的子可扩到 2~3 枚 → 点目标格出招。目标格画出虚线圆圈 + 方向箭头（绿=普通 / 琥珀=推动 / 红=挤出盘外），热区是整格且**画在棋子之上** |
| 昆虫棋 | 点底部**手牌条**的虫卡 → 亮出所有可落点 → 再点一个绿点即放置；点棋盘上己方的棋 → 亮出可去格 → 再点即移动。**悬停**任意棋子会弹出悬停标识（虫种 + 归属，叠层时摊开写清谁压着谁）。滚轮以光标为锚缩放、按住左/中键拖动平移、`F` 把镜头拉回蜂巢 |
| 点格棋 | 鼠标移到两个相邻点之间的边线上会高亮预览（**封口边用绿色**提示），点击画边 |
| 播棋 | 鼠标点己方一侧的小坑播种，悬停会高亮该坑并圈出播种的落点 |

> **昆虫棋的棋子上只有"谁的"，虫种靠剪影 + 悬停标识。** 试过给八种虫各配一种颜色，
> 结果最抢眼的变成虫种色、"哪个是我的"反而要靠推理 —— 敌我识别优先级高得多。

### 快捷键

| 键 | 作用 |
|---|---|
| `U` / `N` | 悔棋 / 新局（对局进行中点「新局」会先弹二级确认） |
| `H` / `?` | 打开规则说明浮层（对局与大厅都可用；大厅里 `R` 也行） |
| `W` / `V` | 开摆放墙模式 / 切换横竖朝向（**仅墙棋**） |
| `F` | 镜头回到蜂巢（**仅昆虫棋**） |
| `1`~`8` | 选中手牌条第 N 种虫（**仅昆虫棋**，再按一次取消） |
| `空格` / `S` | 暂停·继续 / 自对弈单步 |
| `Esc` | **分级**：关浮层 → 取消当前选择 → 退出放墙模式 → 回大厅 → 退出程序 |

## 4. 对局模式与悔棋

侧栏顶部切换 **双人对战 / 人机对战 / AI 自对弈**，参数会**按当前模式 + 当前棋类自动精简**：

- 双人对战：只留棋局设置，AI 相关分组全部隐藏；
- 人机对战：只问两件事 —— **我执哪一方**、**电脑用哪个引擎**（候选里没有"人类"，
  因为选了也会被运行时纠偏，等于"选了没用"）；
- AI 自对弈：才问双方各自的引擎。

悔棋：

- 双人同屏：回退 1 步；
- 人机：一直回退到**轮到你**为止（AI 已应招是 2 步），并立刻取消正在进行的搜索；
- AI 自对弈：回退 1 步并自动暂停。

**AI 自对弈默认暂停**：点侧栏「单步」或直接点棋盘推进一着，点「暂停 / 继续」（或空格）改为连续对弈。

**「新局」「大厅」有二级确认**：已经落过子时点它们会先问一句 —— 这两个按钮紧挨着，
误点一次的代价是整局棋没了。（`Esc` 回大厅不拦，那是明确的退出动作。）

**结算浮层可以关掉**：终局时盖在棋盘上的结果卡片右上角有个 `×`，
关掉之后就只剩棋盘与侧栏，可以慢慢复盘。

## 5. AI

两套算法共用同一个 `Game` 接口，可在侧栏随时切换对比：

- **Minimax（Alpha-Beta）**：负极大值 + Alpha-Beta + 迭代加深 + Zobrist 置换表。
  靠两层剪枝扛住组合爆炸：每个节点只看「对手最短路径附近」的少量墙 / 走法候选，
  并且超过「考虑放墙的层数」后只展开走子。
- **MCTS（UCT）**：UCB1 选点 + 惰性展开 + 启发式 rollout。
  rollout 沿**目标距离场**推进（保证单调收敛，不会来回振荡），并"越快取胜回报越高"塑形。
- 还有一个**随机引擎**做兜底与基准。

搜索跑在**后台线程**里（`AIWorker`），只把结果 `poll()` 回主循环；**AI 线程绝不触碰 pygame**。
所有参数改完**立刻生效**并自动持久化到 `config/settings.json`；改 AI 参数时若正在思考，
会立刻取消并按新参数重搜。滑块也可以**点击右侧数值框直接键入**。

实测吞吐（选引擎时的参考）：

| 棋类 | MCTS 迭代/秒 | 建议 |
|---|---|---|
| 重力四子棋 | ~2090 | Minimax 与 MCTS 都能下好 |
| 步步为营 | ~590 | Minimax depth 4 ≈ 80ms |
| 大力士棋 | ~180 | 把「着法候选上限」调到 20~32（开局 44~80 步） |
| 昆虫棋 | **~83** | 优先 Minimax（d4~6），候选上限 16~32；中局分支因子 100+ |
